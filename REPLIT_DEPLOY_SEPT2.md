🆘 QUICK TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────

PROBLEM: "ModuleNotFoundError: No module named 'flask'"
FIX: Run: pip install flask scikit-learn xgboost pandas numpy

PROBLEM: "FileNotFoundError: xgboost_model.pkl"
FIX: 
  1. Check Files tab - is xgboost_model.pkl there?
  2. Make sure it's in same folder as app.py
  3. Re-upload if needed

PROBLEM: "Address already in use"
FIX:
  1. Click "Stop" button in Replit
  2. Wait 5 seconds
  3. Run: python app.py again

PROBLEM: "Dashboard blank or won't load"
FIX:
  1. Check Shell for red error messages
  2. Make sure Flask is running
  3. Try opening URL in incognito window
  4. Hard refresh: Ctrl+Shift+R

PROBLEM: "Predictions don't change"
FIX:
  1. Check browser console (F12)
  2. Look for JavaScript errors
  3. Try different input values
  4. Refresh page and try again
